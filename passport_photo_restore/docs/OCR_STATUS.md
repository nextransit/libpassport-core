# OCR 端到端状态（诚实记录）

## 结论

- **结构定位 + 去倒影：已达 7/7**（solid 黑带 y~725-770 先验 + 其后 MRZ 两行 + 倒影分界 gap>15px）。
- **扭曲（透视）矫正：已识别（页边梯形、MRZ 行高随 y 变化），但未完成到 OCR 可用。**
- **端到端识别 + decode：0/7 未通过。** CNN 输出全部为粗笔画占位符。

## 卡点（数据物理限制，非算法 bug）

1. 护照机照片 MRZ 带 @1250px 宽图上仅 ~20-51px（2 行合计），**单行 ~10-25px**，  
   远低于 `6_mrz_ocr` 训练分布（36-72px 行高）。放大 4x 后仍模糊。
2. 透视：MRZ 两行左右高度不一致（line1 矮、line2 高），行不水平 → CNN 的  
   pitch-grid 分割失效。
3. 倒影虽已切除，但 MRZ 上方 data 区文字、页面黑带也参与噪声。

## 下一步（要真正 decode 必须做）

1. **单应矫正**：以 MRZ 两行 4 端点（行内文字左右边界 + 上下界）为源四边形，  
   映射到标准 44 格×2 行矩形（如 1088×96px）。这一步解决行不水平+行高不均。
2. **高倍 upscale**：矫正后行高归一到 48px（~4x）。
3. **二值化增强**：局部 Otsu / CLAHE 后再喂 CNN。
4. 若仍失败：训练专用透视-MRZ 识别模型（数据量≥300 张），或改用  
   Tesseract/PaddleOCR ocrb（已有多行支持）。
