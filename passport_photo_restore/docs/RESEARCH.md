# 护照机拍照图 —— 矫正 + 去倒影 + MRZ 识别（研究 + 实施计划）

> 输入：`/Users/zhouyong/gitlab/passport/Photo/2..8`（7 张护照机实拍，2592×1944，7 号 640×480）。
> 现状：现有 `6_mrz_ocr` + `tests/passport_pipeline.py` 在 7 张图上 **0/7 成功**——
> MRZ band 能粗定位，但扭曲（透视/桶形）+ 底部镜面倒影导致 OCR 全失败。
> 本文档：问题量化 → 矫正/去倒影方案 → 端到端识别 → 评估协议。

结论：
1. **扭曲**：护照页边缘在图中是梯形（透视投影），MRZ 行不是水平直线 → 必须做**透视矫正（四点单应）**。
2. **倒影**：MRZ band 之下约 340 行存在反向文字镜像（镜面反射），占比 11–22% →
   需要**底部倒影去除**（带内+带外裁剪 + 边缘重建）。

## 2. 方案选型（按"时间最优 + 固定算法"约束）

约束：不训练大模型（7 张样本不够），用**传统 CV 固定算法**（PIL + numpy，
无第三方 DL 依赖，可移植到 C/NDK/iOS）：

### 2.1 扭曲矫正 —— 四点透视单应（Homography）
- 检测护照页 4 角（页边 = 大尺度亮→暗过渡 / 深色页边角）。
- 用 `cv2.findHomography` / 或纯 numpy 解 8 参数单应，映射到标准页尺寸
  （如 1250×875，ICAO 3:7 页比例）。
- 时间：单应 + remap 在 2592×1944 上 ≈ 3–6 ms（numpy/cv2 向量化）。
- **固定性**：护照机摆放相对固定 → 4 角位置稳定，单应矩阵可预先校准并缓存；
  实时只做 `warpPerspective`。

### 2.2 去底部倒影 —— 结构感知裁剪 + 内容重建
- 倒影 = MRZ 带的垂直镜像，位于 band 之下约 1.05× band 高度处。
- 方案 A（时间最优，推荐）：**带内定位 MRZ 精确 y 范围后，仅取 band 以上 +
  band 本身（含少量 pad），丢弃 band 以下全部倒影**；再用带内行投影锁定
  MRZ 起止，输出"无倒影"的 MRZ crop。
- 方案 B（更稳，代价 +2ms）：倒影区域检测对称相关性（band 与其下方窗口的
  列结构相关系数），只裁掉相关度高的倒影区。
- 关键：现有 `_locate_mrz` 的"两行签名"在倒影干扰下失效 → 需在**矫正后**图
  上重跑 band 定位（倒影区仍在下，但单应后 MRZ 高度变大、更易识别）。

### 2.3 MRZ 识别 + 解码（复用现有，时间最优）
- 现有 `6_mrz_ocr` CNN/template + `1_mrz_decode` 已经可用且是纯 C（<1 ms）。
- 端到端路径：`restore(img) -> locate_mrz -> ocr_crop(upscale) -> decode`。
- 目标：p50 < 20 ms（全流程含 IO）。

## 3. 端到端流水线（目标）

```
Photo (2592x1944)
  ├─ [T0] 降采样到 ~1250px 宽 (LANCZOS)         ~2ms
  ├─ [T1] 页边检测 + 4 角 (大尺度亮度过渡)       ~3ms
  ├─ [T2] 单应矫正 → 标准页 (warpPerspective)    ~4ms
  ├─ [T3] 行投影 → MRZ band 定位 (band+倒影分离) ~2ms
  ├─ [T4] crop MRZ（去倒影，只留 band+小 pad）   ~1ms
  ├─ [T5] 若 MRZ 行高 <30px: LANCZOS 放大        ~2ms
  ├─ [T6] 6_mrz_ocr CNN 识别 line1/line2         ~1ms
  └─ [T7] 1_mrz_decode 解码 (ICAO 校验)          ~0.5ms
  总目标 p50 ≈ 15-20ms
```

## 4. 评估协议

指标（7 张图，逐张 + 汇总）：
1. **矫正质量**：4 角残差（单应后页边是否水平/垂直直线）、MRZ 行水平度
   （行投影峰度）。
2. **倒影去除质量**：MRZ crop 内倒影像素占比（应 <2%）；band 下方镜像
   相关系数（应 <0.2）。
3. **MRZ 识别**：line1/line2 字符准确率（对合成 GT 的编辑距离）、
   `mrz_ocr_cnn_tool` 输出 conf。
4. **解码**：`mrz_tool decode` ok/不 ok + 字段命中率。
5. **时间**：T0..T7 分阶段 + 全流程 p50/p95（同 AArch64 纪律）。

### 已知坑（必须验证）
- 页边检测阈值：2592×1944 下页边暗像素宽度大，Otsu/行投影需先降采样。
- 透视矫正的 4 角不稳定：若一页角被倒影遮挡，需用 3 点 + 页比例约束。
- MRZ 在透视下高度变化：单应后行高从 ~10px → ~40px，直接改善 OCR。
