# Passport Test Bench (护照机测试机)

Six independent C99 modules + a Tkinter test-bench GUI for the
ICAO passport machine pipeline (MRZ + anti-counterfeit + face matching
+ eMRTD chip read + cryptography).

```
passport/
├── 1_mrz_decode/         ICAO 9303 TD3 encoder + decoder + check digits
├── 2_anticounterfeit/    Doc-type / country / date / entropy rules
├── 3_face_recognition/   PPM/BMP I/O, aHash, pHash, similarity
├── 4_nfc_reader/          ICAO BAC mock + APDU choreography
├── 5_integration_test/   End-to-end driver script (run_integration.py)
├── 6_mrz_ocr/            MRZ image recognition (traditional + CNN)
└── 7_security/            SHA-1 + DES/3DES + AES-128 + BAC + cross-modal
```

## Quick start

```sh
# Build & unit-test each module.
cd 1_mrz_decode       && ./run.sh && cd ..
cd 2_anticounterfeit  && ./run.sh && cd ..
cd 3_face_recognition && ./run.sh && cd ..
cd 4_nfc_reader       && ./run.sh && cd ..
cd 6_mrz_ocr          && ./run.sh && cd ..
cd 7_security         && ./run.sh && cd ..

# Run the integration driver (drives every CLI in sequence).
python3 5_integration_test/run_integration.py
# -> integration_results.md  (per-stage timing + output)

# Run the GUI.
python3 tests/gui.py
```

## 1. MRZ decoder/encoder
ICAO Doc 9303 Part 4 (TD3 passport MRZ):
* Strict character set (`[A-Z0-9<]`)
* Weight-cycle check digits 7,3,1
* Composite check digit over line 2 (positions 0..42)
* Round-trip encode + decode
* Auto uppercases + maps spaces to `<`

## 2. Anti-counterfeit verifier
On top of MRZ decoding:
* Document type prefix in the ICAO 9303 list
* Country codes are 3-letter uppercase
* Sex is `M`/`F`/`<`
* Birth / expiry dates parse as YYMMDD with valid month/day
* Expiry > birth; age and expiry horizons
* Name entropy (alphabetic content vs filler)
* Personal number presence
* Check-digit consistency

## 3. Face matching
* PPM (P6) and 24-bit BMP I/O
* Grayscale + histogram equalisation
* aHash (8x8 mean-threshold) and pHash (8x8 DCT median-threshold)
* Hamming-distance similarity score (0..100)

## 4. NFC reader mock
A backend abstraction that replays a JSON script of APDUs through
the full e-Passport BAC read sequence:
* SELECT AID A0000002471001
* GET CHALLENGE
* MUTUAL AUTHENTICATE (x2)
* SELECT DG1 + READ BINARY
* SELECT SOD + READ BINARY

Two scripts in `data/` cover the happy-path and a failure-path.

## 5. Integration test
`run_integration.py` drives every CLI in order, recording per-stage
wall-clock time and printing a markdown report.

## 6. MRZ image OCR (traditional + CNN)
Two recognition paths in one module:
* **Traditional**: embedded OCR-B template bank + normalised
  correlation. ~88-93% line-level accuracy on the synthetic corpus.
* **CNN**: lightweight MLP (96 raw pixels -> 96 -> 37), float32,
  trained with numpy on the OCR-B templates + light augmentation.

A corpus of 108 synthetic images is generated by
`tests/gen_corpus.py`. `tests/benchmark.py` writes
`bench_results.{json,md,txt}` with side-by-side numbers
(run `python3 6_mrz_ocr/tests/bench.py` to regenerate):

```
| method       | ms mean | ms p95 | line1 acc | line2 acc |
|--------------|---------|--------|-----------|-----------|
| traditional  | 5.3     | 7.0    | 88.7%     | 93.1%     |
| cnn          | 5.4     | 7.1    | 80.1%     | 78.0%     |
```

CNN line-level accuracy jumped from 0.8%/2.8% (the earlier int8
fixed-point build, which mis-scaled weights and collapsed to a single
class) to 80.1%/78.0% after fixing the trainer/inference feature
alignment and switching to float32 weights. Traditional template
matching still leads on clean text; CNN trails on the first (name /
document number) line but is close on the second (numeric) line.

## 7. Security
ICAO Doc 9303 Part 11 + Part 12 building blocks:
* SHA-1 (FIPS 180-4)
* DES + 3DES (CommonCrypto on macOS, OpenSSL on Linux)
* AES-128 ECB / CBC
* ISO/IEC 9797-1 MAC Algorithm 3 (retail MAC)
* ICAO BAC key derivation (SHA-1 -> K_enc/K_mac)
* Cross-modal consistency check (MRZ vs VIZ text)
* B900 IR absorption check
* SSIM template match for IR watermark
* UV fluorescence check

All primitives validated against NIST/FIPS test vectors.

## GUI

`tests/gui.py` is a single-window Tkinter app with five tabs, in order:

1. **MRZ OCR 测试** — corpus-driven benchmark (108 cases) across
   traditional vs CNN, with a side-by-side stats table, per-case
   detail, and an inline image preview when you click a case row.
2. **NFC 读卡** — full mock eMRTD R-APDU choreography (select,
   challenge, BAC mutual-auth, DG1/SOD readback) driven from a
   `4_nfc_reader/data/*.json` mock script, with a 8-step APDU trace.
3. **MRZ 解码** — decode + check digits of the two-line MRZ on the
   left, or encode the 10 TD3 fields on the right into an MRZ string.
4. **防伪验证** — runs `ac_tool` over the MRZ text and shows the
   structured verification report.
5. **照片比对** — two PPM/BMP pickers + `face_tool` similarity.

The window carries the app icon from `tests/assets/app_icon.png`
(generated by `tests/assets/make_icon.py`), and a status bar at the
bottom reports which CLIs are present.
